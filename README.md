# DevViz — 動かして学ぶ開発用語

React・Node.js・非同期処理・HTTP・DOM・Git など、開発の用語を
**実例**と**アニメーション**で動かしながら学べる学習サイトです。

文字の説明だけでは掴みにくい概念を、ブラウザ上で実際に「動かして」
体感することで理解できます。ビルド不要・依存ゼロの静的サイトなので、
ファイルを開くだけで動きます。

## 収録している用語

| 用語 | 学べること | デモ |
| --- | --- | --- |
| 🌳 DOM | HTMLが触れるオブジェクトの木であること | ツリーをクリックすると表示が光る |
| ⚛️ React / state | stateと再レンダー、仮想DOMの差分 | カウンターと仮想DOMの差分表示 |
| ⏳ 非同期処理 / Promise | 同期と非同期(並行)の違い | タイムラインで合計時間を比較 |
| 🔁 イベントループ | console.log の出力順の理由 | スタック/キュー/出力をステップ表示 |
| 🌐 HTTP / API | リクエストとレスポンスの往復 | パケットが飛ぶアニメーション |
| 🟢 Node.js | ブラウザ外でJSを動かす実行環境 | 擬似サーバーへのリクエスト |
| 🔀 Git / ブランチ | コミット・ブランチ・マージ | 履歴グラフを育てる |
| 📐 CSS Flexbox | レイアウトプロパティの効果 | リアルタイムプレイグラウンド |
| 📦 変数とデータ型 | typeof と型ごとの操作 | 値を入れて型判定 |

## 特長

- **動くデモ重視** — 各用語に必ずインタラクティブなデモを用意
- **進捗の記録** — 閲覧済みの用語に ✓ が付き、進捗バーに反映（localStorage）
- **検索** — 用語名・説明・タグから絞り込み
- **ダーク / ライトテーマ** — 右上のボタンで切替（設定は保存される）
- **レスポンシブ** — スマホでもサイドバーがメニュー化されて使える
- **依存ゼロ** — フレームワークもビルドも不要のバニラ HTML / CSS / JS

## 使い方

ローカルで開く場合:

```bash
# そのままブラウザで index.html を開くだけでOK
open index.html        # macOS
xdg-open index.html    # Linux

# もしくは簡易サーバーで
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
このブランチの root を公開元に設定すればそのまま動きます。

## ディレクトリ構成

```
.
├── index.html            # エントリーポイント
└── assets/
    ├── css/style.css     # スタイル（テーマ変数・デモ用CSS）
    └── js/
        ├── concepts.js   # 用語データ（説明・タグ・対応デモ）
        ├── demos.js      # 各インタラクティブデモの実装
        └── app.js        # ナビ / ルーティング / テーマ / 進捗
```

## 用語を追加するには

1. `assets/js/concepts.js` の `CONCEPTS` 配列に項目を追加
   （`id` / `icon` / `title` / `group` / `summary` / `tags` / `body` / `demo`）
2. デモが必要なら `assets/js/demos.js` に `mountXxxDemo(el)` を実装し、
   その関数名を `concept.demo` に指定

ナビゲーション・検索・前後リンク・進捗は自動で反映されます。
